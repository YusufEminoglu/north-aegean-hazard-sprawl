# Security policy

Please do not open a public issue if you discover a credential, private Earth
Engine asset identifier, access token, personal path, or other sensitive
operational detail.

Contact the corresponding author at yusuf.eminoglu@deu.edu.tr with a concise
description and the affected path. Do not copy the secret itself into email
unless a secure transfer method has been agreed.

For ordinary scientific bugs and reproducibility problems, use the public issue
templates.
